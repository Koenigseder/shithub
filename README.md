# ShitHub Chromium extension

This Chromium extension renames every occurrence of "GitHub" to "ShitHub".
Also, it displays an uptime badge in the bottom right corner, with stats from [The Missing GitHub Status Page](https://mrshu.github.io/github-statuses/).

Badge color:
- Uptime >= 99.9 &rarr; green
- Uptime >= 99.0 &rarr; amber
- Uptime < 99.0 &rarr; red
